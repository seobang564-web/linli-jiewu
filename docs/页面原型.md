# 页面原型（隋骐泽 · 第 1 周）

> 底部导航四个主页面 + 详情页的信息结构、交互原则与空壳验收标准。
> 实现以本文件为原型依据；改动先在周会同步并更新本文档。

## 全局框架

- 底部导航固定四项：**发现 · 发布 · 借还 · 我的**（`HomeActivity` + `BottomNavigationView` + `ViewPager2`，左右滑与点按均可切换）。
- 发现页复用现有 `DiscoverFragment`（地图 + 定位），其余三页本周为空壳，仅证明导航与页面容器可用。
- 状态色全组统一（见 `colors.xml`）：可借 `#236950`、已预约 `#996500`、借出中 `#276195`、已下架 `#68746C`，文字 + 颜色双通道标识。
- 每个页面统一处理"加载中 / 成功 / 失败 / 空"四种状态；失败保留用户已输入内容。

## 1. 发现页（已有，方舒煜负责）

```
┌──────────────────────────┐
│ 搜索框 + 半径按钮          │  ← 第 3 周接入检索
├──────────────────────────┤
│                          │
│        地 图             │  ← 当前位置 + 物品标记（第 3 周）
│                          │
├──────────────────────────┤
│ ▔▔ 可展开结果列表 ▔▔      │  ← 物品卡片：名称/缩略图/距离/状态
└──────────────────────────┘
```

交互：点击地图标记或列表卡片 → 同一详情页；标记与列表严格同步。

## 2. 发布页（隋骐泽 · 第 2 周实现）

```
┌──────────────────────────┐
│ 物品照片  [选择图片]       │  ← 相册选择 + 压缩预览，可重选
│ ┌────┐                   │
│ │预览 │  压缩后大小/尺寸   │
│ └────┘                   │
│ 名称*    [__________]     │  ← 1–50 字
│ 分类*    [下拉选择   ▼]   │  ← TOOL/LUGGAGE/CAMPING/SPORTS/ELECTRONICS/BOOK/OTHER
│ 描述     [多行输入____]   │  ← ≤500 字，可选
│ 公共交接点* [待选点组件]   │  ← 方舒煜第 2 周提供选点组件，此前为占位
│ [      发 布      ]       │  ← 校验 → 上传图片 → POST /items
└──────────────────────────┘
```

交互：必填项缺失时逐项提示；提交中按钮禁用并显示进度；失败保留全部输入。

## 3. 借还页（空壳 · 第 4 周实现）

```
┌──────────────────────────┐
│ [ 我借入的 ] [ 我借出的 ]  │  ← 顶部身份切换
├──────────────────────────┤
│  订单卡片列表（空）        │
│  "暂无进行中的借还"        │
└──────────────────────────┘
```

按身份分区，订单卡片含物品缩略图、状态色、下一步操作按钮（接受/交接/归还/验收，第 4 周接入）。

## 4. 我的页（空壳 · 第 3 周起填充）

```
┌──────────────────────────┐
│  头像  昵称（登录后显示）   │
├──────────────────────────┤
│  我的发布  >              │  ← 第 3 周
│  本地草稿  >              │  ← 第 3 周 SQLite
│  服务连接自检  >           │  ← 跳转 bootstrap 自检页
└──────────────────────────┘
```

## 5. 详情页（隋骐泽 · 第 2 周实现，Activity 而非导航项）

```
┌──────────────────────────┐
│  物品大图                  │
│  名称        [可借]       │  ← 状态 Chip，用统一状态色
│  分类 · 距离               │
│  描述文本                  │
│  公共交接点：东门快递站旁   │
│  物主：昵称                │
│ [    预约借用    ]        │  ← 登录后可用；未登录提示先登录
└──────────────────────────┘
```

数据来源：第 2 周由发布成功跳转 + Intent 传参；第 3 周接入 `GET /items/{id}` 后改为按 id 拉取。

## 第 1 周空壳验收标准

1. 启动应用直接进入底部导航主页，四个 Tab 可点按与滑动切换。
2. 发现页地图、定位、隐私弹窗功能与独立调试期一致（回归无损）。
3. 发布 / 借还 / 我的三个空壳显示占位文案与各自实现计划说明。
4. bootstrap 自检页保留，可从"我的 → 服务连接自检"进入。
