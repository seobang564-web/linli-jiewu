# 云服务器部署说明

## 环境

- Linux 云服务器（Ubuntu 22.04 或同类），1 核 2G 起
- JDK 17、MySQL 8
- 安全组放行 TCP 8080（应用）；22 仅限自己 IP；**不要对公网开放 3306**

## 步骤

1. 安装 JDK 与 MySQL，创建数据库与专用账号（不要用 root 连接）：
   ```sql
   CREATE USER 'linli'@'localhost' IDENTIFIED BY '<强密码>';
   GRANT ALL ON linli_jiewu.* TO 'linli'@'localhost';
   ```
2. 执行 `docs/数据库设计.sql`，再按需执行 `server/src/main/resources/db/seed.sql`。
3. 在服务器 `/opt/linli/` 放置 `application-prod.yml`（数据库密码、JWT 密钥、图片目录），不进 Git。
4. 本地 `mvn -DskipTests package`，把 jar 上传到 `/opt/linli/app.jar`。
5. 用 systemd 守护：
   ```ini
   # /etc/systemd/system/linli.service
   [Unit]
   Description=linli-jiewu server
   After=network.target mysql.service

   [Service]
   WorkingDirectory=/opt/linli
   ExecStart=/usr/bin/java -Duser.timezone=Asia/Shanghai -jar app.jar --spring.profiles.active=prod --spring.config.additional-location=/opt/linli/
   Restart=always
   User=linli

   [Install]
   WantedBy=multi-user.target
   ```
   `sudo systemctl enable --now linli`
6. 验证：`curl http://<服务器IP>:8080/api/items?lat=30.5&lng=114.4`

## 客户端配置

- 服务器地址写在 `android/local.properties`：`server.baseUrl=http://<IP>:8080/api/`
- 因使用 HTTP 明文，需在 `res/xml/network_security_config.xml` 允许明文流量，并在 Manifest 引用。
