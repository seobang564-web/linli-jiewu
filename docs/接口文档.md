# 接口文档 v0.3

前后端唯一接口契约。改接口先改本文件（见《开发约定》第 4 节）。

## 0. 通用约定

- Base URL：`http://<服务器IP>:8080/api`
- 鉴权：请求头 `Authorization: Bearer <token>`；标注 🔒 的接口必须登录。
- 编码：请求与响应均为 `application/json; charset=utf-8`（图片上传除外）；JSON 接口收到不支持的请求类型返回 400 / 40001。
- 时间：ISO 8601，带时区，例如 `2026-11-20T18:00:00+08:00`。
- 坐标：GCJ-02，`lat` / `lng` 为十进制度数，保留 7 位小数。
- 距离与半径：单位米，整数。
- 分页：`page` 从 1 开始，`size` 默认 20、最大 50。

### 统一响应

```json
{ "code": 0, "message": "ok", "data": { } }
```

分页数据：

```json
{ "code": 0, "message": "ok",
  "data": { "total": 42, "page": 1, "size": 20, "list": [ ] } }
```

### 错误码

| code | HTTP | 含义 |
| --- | --- | --- |
| 0 | 200 | 成功 |
| 40001 | 400 | 参数校验失败（message 说明字段） |
| 40101 | 401 | 未登录或 Token 失效 |
| 40301 | 403 | 无权操作（不是物主 / 借用者） |
| 40401 | 404 | 资源不存在或已下架 |
| 40901 | 409 | 状态冲突（如物品已被预约、订单状态不允许此操作） |
| 40902 | 409 | 用户名已存在 |
| 40903 | 409 | 不能借用自己的物品 |
| 41301 | 413 | 图片过大 |
| 50000 | 500 | 服务器内部错误 |
| 50301 | 503 | 数据库连接或基础表未就绪 |

### 第一周验收接口

#### `GET /hello`（游客可用）

确认 Java 服务和 HTTP 路由可用，不访问数据库。完整路径为 `/api/hello`。

```json
{ "code": 0, "message": "ok", "data": { "service": "linli-jiewu", "message": "Hello, 邻里借物地图！", "time": "2026-11-18T12:00:00+08:00" } }
```

#### `GET /health`（游客可用）

通过 MyBatis 检查数据库连接及七张基础表（含第 2 周新增的 `images`）是否可读，不返回账户、连接地址、密码或业务数据。已有环境须先执行 `docs/migrations/002_images.sql`。

```json
{ "code": 0, "message": "ok", "data": { "status": "UP", "database": "UP", "schema": "UP" } }
```

连接失败或缺少基础表时返回 HTTP 503：

```json
{ "code": 50301, "message": "数据库连接或基础表未就绪", "data": null }
```

Hello 成功只说明应用可访问；第一周服务端验收要求 Hello 和 health 均成功。以上接口不改变后续业务接口的鉴权要求。

## 1. 枚举

### 物品分类 `Category`
`TOOL` 工具｜`LUGGAGE` 行李箱包｜`CAMPING` 露营户外｜`SPORTS` 运动｜`ELECTRONICS` 电子设备｜`BOOK` 书籍｜`OTHER` 其他

### 物品状态 `ItemStatus`
| 值 | 含义 |
| --- | --- |
| `AVAILABLE` | 可借 |
| `RESERVED` | 已预约（有待确认或待交接订单） |
| `LENT` | 借出中（借用中或待验收） |
| `OFFLINE` | 已下架（不参与检索） |

### 订单状态 `BorrowStatus`
| 值 | 含义 |
| --- | --- |
| `PENDING` | 待确认 |
| `ACCEPTED` | 待交接 |
| `BORROWING` | 借用中 |
| `RETURNING` | 待验收 |
| `COMPLETED` | 已完成 |
| `CANCELLED` | 已取消 |

### 取消类型 `CancelType`
`REJECTED` 物主拒绝｜`OWNER_CANCEL` 物主取消｜`BORROWER_CANCEL` 借用者取消｜`EXPIRED` 超时自动取消

## 2. 状态机

| 操作 | 接口 | 操作人 | 订单 | 物品 |
| --- | --- | --- | --- | --- |
| 提交申请 | `POST /borrows` | 借用者 | 新建 → `PENDING` | `AVAILABLE` → `RESERVED` |
| 接受 | `POST /borrows/{id}/accept` | 物主 | `PENDING` → `ACCEPTED` | 保持 `RESERVED` |
| 拒绝 | `POST /borrows/{id}/reject` | 物主 | `PENDING` → `CANCELLED`(REJECTED) | → `AVAILABLE` |
| 交接前取消 | `POST /borrows/{id}/cancel` | 双方 | `PENDING`/`ACCEPTED` → `CANCELLED` | → `AVAILABLE` |
| 确认交接 | `POST /borrows/{id}/handover` | 物主 | `ACCEPTED` → `BORROWING` | `RESERVED` → `LENT` |
| 申请归还 | `POST /borrows/{id}/return` | 借用者 | `BORROWING` → `RETURNING` | 保持 `LENT` |
| 验收通过 | `POST /borrows/{id}/confirm-return` | 物主 | `RETURNING` → `COMPLETED` | `LENT` → `AVAILABLE` |
| 验收不通过 | `POST /borrows/{id}/deny-return` | 物主 | `RETURNING` → `BORROWING` | 保持 `LENT` |
| 超时 | 定时任务 | 系统 | `PENDING` 超过 **12 小时** → `CANCELLED`(EXPIRED) | → `AVAILABLE` |

规则：
- 同一物品同时最多一笔 `PENDING/ACCEPTED/BORROWING/RETURNING` 订单，由 `items.active_borrow_id` 记录。
- 释放物品前核对 `items.active_borrow_id == 当前订单 id`。
- 超过 `dueAt` 仅标记 `overdue: true`，不自动释放。
- 超时判定：定时任务每分钟扫描；`accept` 时也再次检查 `expiresAt`，已过期返回 40901。
- 所有状态变化写入 `borrow_logs`。

## 3. 账户

### `POST /auth/register`
```json
{ "username": "fsy01", "password": "******", "nickname": "舒煜", "contact": "微信 xxx" }
```
- username 4–20 位字母数字下划线；password 6–32 位且 UTF-8 不超过 72 字节；nickname 必填，去首尾空格后 1–32 字；contact 可选，最多 64 字。
- 返回同登录。

### `POST /auth/login`
```json
{ "username": "fsy01", "password": "******" }
```
返回：
```json
{ "token": "eyJ...", "expiresIn": 604800,
  "user": { "id": 1, "username": "fsy01", "nickname": "舒煜" } }
```

### 🔒 `GET /users/me` ／ 🔒 `PUT /users/me`
PUT 可修改 `nickname`、`contact`。
返回 `{ "id": 1, "username": "fsy01", "nickname": "舒煜", "contact": "微信 xxx" }`，联系方式只在本人资料及符合权限的订单中返回。PUT 中 nickname 必填，contact 为 null 时清空。
Token 有效期 7 天；公开物品详情允许游客访问，携带无效 Token 时返回 40101。注册、登录、Hello 和 health 不读取现有 Token。客户端收到 401 清除该次请求使用的旧 Token，不清除请求期间新登录的会话。

## 4. 图片

### 🔒 `POST /images`
- `multipart/form-data`，字段 `file`；仅 jpg / png / webp，≤ 5 MB。
- 服务端重新编码（去除 EXIF 位置信息）并随机命名。
- 按真实内容解码，最长边 8192、总像素不超过 2000 万；超限或无法解码返回 40001。统一保存为 PNG，最大上传大小按 5 × 1024 × 1024 字节判断。
- `images` 表记录上传者、随机文件名、字节数和创建时间。发布/编辑只允许使用本人上传且存在的 imageId，允许同一上传者重复引用；文件通过 `/files/{随机文件名}` 公开读取。
- 图片存放于 `UPLOAD_DIR`，不存入数据库；当前版本保留未引用图片，不自动清理，避免误删订单快照引用。
```json
{ "imageId": "a1b2c3d4e5f60718293a4b5c6d7e8f90", "url": "/files/a1b2c3d4e5f60718293a4b5c6d7e8f90.png" }
```

## 5. 物品

### `GET /items` 附近检索（游客可用）

| 参数 | 必填 | 说明 |
| --- | --- | --- |
| lat, lng | 是 | 搜索中心 |
| radius | 否 | 米，100–10000，默认 1000 |
| keyword | 否 | 去首尾空格后对标题、描述子串匹配，英文不区分大小写 |
| category | 否 | 分类枚举 |
| status | 否 | 逗号分隔，默认 `AVAILABLE`；不可传 `OFFLINE` |
| page, size | 否 | 分页 |

排序：`distanceM` 升序，相同时 `id` 升序。距离为球面直线距离（Haversine，地球半径 6371008.8 米），按原始米数与半径比较。

列表项：
```json
{ "id": 12, "title": "双人帐篷", "category": "CAMPING", "coverUrl": "/files/x.jpg",
  "status": "AVAILABLE", "distanceM": 486,
  "pickupLabel": "东门快递站旁", "pickupLat": 30.5123456, "pickupLng": 114.4123456 }
```

### `GET /items/{id}`
在列表项基础上增加：`description`、`owner { id, nickname }`、`createdAt`、`isMine`（登录时）。可选参数 `lat,lng` 用于返回距离。

### 🔒 `POST /items` 发布
```json
{ "title": "双人帐篷", "category": "CAMPING", "description": "…",
  "imageId": "a1b2c3d4e5f60718293a4b5c6d7e8f90", "pickupLat": 30.5123456, "pickupLng": 114.4123456,
  "pickupLabel": "东门快递站旁" }
```
title 1–50 字；description ≤ 500 字；返回物品详情。
`description` 缺省/null 归一化为空串；`imageId` 缺省/null 表示无图。`pickupLabel` 去首尾空格后 1–100 字，经纬度必须同时提供且位于合法范围（纬度 -90–90，经度 -180–180）。
详情的 `coverUrl` 无图为 null，`distanceM` 仅传入 lat/lng 时返回；不暴露物主联系方式。下架物品详情仅物主可读，其他人返回 40401。

### 🔒 `PUT /items/{id}` 编辑（仅物主）
字段同发布。存在进行中订单时不可修改交接点（40901）。
编辑不会改变物品状态；下架物品不能通过编辑重新上架。图片清空由 `imageId: null` 表示。

### 🔒 `POST /items/{id}/offline` 下架（仅物主）
有进行中订单返回 40901。

### 🔒 `GET /users/me/items`
我的发布，参数 `status`、`page`、`size`。
status 可为逗号分隔的物品状态，缺省包含全部状态；按 id 降序。返回统一分页结构，list 为物品详情。第 2 周双账户验收可由账户 A 发布后，将物品 id 交给账户 B 调用公开详情；附近检索由方舒煜第 3 周负责。

## 6. 借用

### 🔒 `POST /borrows` 提交申请
```json
{ "itemId": 12, "dueAt": "2026-11-22T18:00:00+08:00",
  "note": "周末露营用", "requestId": "客户端生成的UUID" }
```
- 同一借用者重复提交相同 `requestId`，返回第一次创建的订单（幂等）。
- `itemId` 为正整数；首次申请的 `dueAt` 必须晚于服务器当前时间，需带时区；统一转换为上海时间存储，精度为秒，输入及转换后的年份均须在 1000–9999。`note` 可省略/null，归一化为空串，最多 200 字。
- `requestId` 为 1–64 位字母、数字、下划线或短横线，推荐 UUID；统一转小写，与数据库唯一键的大小写语义一致。幂等范围为“借用者 + requestId”。客户端重试须沿用原编号；即使重试时参数改变、原归还时间已过或订单已结束，也返回原订单的当前详情，不创建新订单。
- 申请仅允许非物主对 `AVAILABLE` 且无活动订单的物品发起；自己的物品返回 40903，不可借状态返回 40901，下架/不存在物品返回 40401。
- 创建订单、占用物品及初始日志处于同一事务，失败全部回滚。并发申请同一物品最多成功一笔；重复幂等号不会留下额外订单或占用其他物品。
- 返回订单详情。

### 🔒 `GET /borrows`
| 参数 | 说明 |
| --- | --- |
| role | `borrower` 我借入的 ／ `owner` 我借出的（必填） |
| status | 可选，逗号分隔 |
| page, size | 分页 |

返回统一分页结构，list 为订单详情；按订单 id 降序。role 仅允许上述两值，status 仅允许订单状态枚举（多个状态去重），非法或空状态返回 40001；page ≥ 1，size 为 1–50。仅查询 Token 所属用户的订单。

### 🔒 `GET /borrows/{id}` 订单详情（仅双方）
```json
{ "id": 5, "status": "ACCEPTED", "overdue": false,
  "item": { "id": 12, "title": "双人帐篷", "coverUrl": "…", "pickupLabel": "…", "pickupLat": 0, "pickupLng": 0 },
  "owner": { "id": 1, "nickname": "舒煜", "contact": "微信 xxx" },
  "borrower": { "id": 2, "nickname": "骐泽", "contact": null },
  "dueAt": "…", "expiresAt": "…", "note": "…",
  "cancelType": null, "cancelReason": null,
  "conversationId": 8, "createdAt": "…", "updatedAt": "…" }
```
- `contact` 仅在 `ACCEPTED/BORROWING/RETURNING/COMPLETED` 返回；`PENDING/CANCELLED` 为 null。列表、创建及状态操作响应遵循相同规则。
- `item` 字段来自下单时的快照。
- `overdue` 表示尚未结束且已超过 dueAt；`COMPLETED/CANCELLED` 恒为 false，逾期不自动释放物品。
- 第 3 周复用已存在的“物品 + 借用者”会话；尚无会话时 `conversationId` 为 null，聊天接口与会话创建留待第 4 周接入。

### 🔒 状态操作
`POST /borrows/{id}/accept | reject | cancel | handover | return | confirm-return | deny-return`

请求体（可选）：`{ "reason": "…" }`；`reject`、`cancel`、`deny-return` 建议填写原因。返回更新后的订单详情。

reason 最多 200 字，去首尾空格后为空则存 null。身份校验先于状态校验：非双方、或操作身份不符返回 40301；非法状态、重复操作、活动订单指针不匹配返回 40901，不新增日志或改变物品。accept 在锁内复核 expiresAt（到期即拒绝），返回 40901，待第 4 周超时任务统一取消。所有写操作固定先锁物品、后锁订单。

### 🔒 `GET /borrows/{id}/logs`
```json
[ { "fromStatus": null, "toStatus": "PENDING", "actor": { "id": 2, "nickname": "骐泽" },
    "reason": null, "createdAt": "…" } ]
```
系统操作 `actor` 为 null。
仅订单双方可读，按日志 id 升序；从创建申请起，每次成功状态变化恰好一条日志。订单不存在返回 40401，非双方访问详情/日志返回 40301。

## 7. 即时聊天

会话以“物品 + 借用者”唯一确定：借用者在物品详情页点“联系物主”即创建或进入会话；后续申请的订单关联同一会话。只有物主和该借用者可见。

### 🔒 `POST /conversations` 获取或创建
```json
{ "itemId": 12 }
```
物主不能对自己的物品创建（40903）。返回会话对象。

### 🔒 `GET /conversations` 我的会话列表
按 `lastMessageAt` 倒序：
```json
{ "id": 8, "item": { "id": 12, "title": "双人帐篷", "coverUrl": "…" },
  "peer": { "id": 2, "nickname": "骐泽" },
  "lastMessage": "明天下午可以吗", "lastMessageAt": "…", "unread": 2 }
```

### 🔒 `GET /conversations/{id}/messages`
| 参数 | 说明 |
| --- | --- |
| beforeId | 向上翻历史，返回 id 小于它的消息 |
| afterId | 补拉新消息（断线重连、轮询用） |
| limit | 默认 30，最大 100 |

消息对象：
```json
{ "id": 101, "conversationId": 8, "senderId": 2, "content": "明天下午可以吗",
  "clientMsgId": "uuid", "createdAt": "…" }
```

### 🔒 `POST /conversations/{id}/messages` 发送
```json
{ "content": "明天下午可以吗", "clientMsgId": "客户端UUID" }
```
- content 1–1000 字。同一发送者重复的 `clientMsgId` 返回已有消息（防重复发送）。
- 保存成功后通过 WebSocket 推送给对方。

### 🔒 `POST /conversations/{id}/read`
将本人在该会话的未读数清零。

### WebSocket 推送
- 地址：`ws://<服务器IP>:8080/ws?token=<token>`
- 只用于服务端推送；**发送消息一律走 REST**。
- 推送格式：
```json
{ "type": "MESSAGE", "data": { 消息对象 } }
{ "type": "BORROW_UPDATED", "data": { "borrowId": 5, "status": "ACCEPTED" } }
```
- 客户端每 30 秒发送文本 `ping`，服务端回 `pong`。
- 断线后指数退避重连（1、2、4… 最长 30 秒）；断线期间聊天页每 5 秒用 `afterId` 轮询兜底，重连后补拉一次。
